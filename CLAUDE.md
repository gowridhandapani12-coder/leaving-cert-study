# Leaving Cert Study Lab (all subjects)

Free, interactive study pages for the Irish Leaving Certificate, one self-contained HTML page per topic, all sharing
one design (palette, fonts, dark mode, top tabs + sidebar, visual-first). This folder is the single project and the
GitHub repository (`gowridhandapani12-coder/leaving-cert-study`, public). Live site (GitHub Pages, from `main`):
https://gowridhandapani12-coder.github.io/leaving-cert-study/ . Every push to `main` republishes it within a minute or two.

| Folder | Subject | Notes |
|--------|---------|-------|
| `physics/` | Physics (new spec, exam 2027+) | `physics/CLAUDE.md` holds the master format rules and quality checks |
| `business/` | Business (new spec, exam 2027+) | `business/CLAUDE.md` |
| `maths/` | Maths (2015 syllabus) | `maths/CLAUDE.md` |
| `applied-maths/` | Applied Maths (2019 spec) | `applied-maths/CLAUDE.md` |
| `english/` | English (current syllabus, exam to 2028) | `english/CLAUDE.md` |
| `spanish/` | Spanish (current syllabus) | `spanish/CLAUDE.md` |
| `irish/` | Irish / Gaeilge (current syllabus) | `irish/CLAUDE.md` |

Each subject folder has its own `CLAUDE.md` (spec, format, quality checks) and `COURSE-PLAN.md` (build order, run log).
Read the subject's notes before building a page in it.

## Site structure

- `index.html` (home) and each subject's `index.html` (hub) are generated by `node tools/site.js`, except the
  hand-made hubs `physics/index.html` and `business/index.html` (kept; only their subject tabs are refreshed).
- `tools/site.js` also adds the subject tabs (Home · Physics · Business · Maths · Applied Maths · English · Spanish · Irish)
  to the top bar of every page, between `<!--subj-nav-->` markers. It is idempotent: **run it after every new page**.
  To add a subject, add it to `SUBJECTS` in `tools/site.js`.
- Links are relative (`../physics/index.html`), so the site works from a local server, from GitHub Pages, or as files.

## Run it locally

```
node server.js
```
Then open http://localhost:5190 (the whole site). Each subject folder also has its own `server.js` on its old port.
The preview config is "studysite".

## After building a page

1. Run the subject's quality checks (see its CLAUDE.md and `physics/CLAUDE.md`).
2. `node tools/site.js`
3. Update the subject's `COURSE-PLAN.md` (row done + run log) and the "Built so far" line in its `CLAUDE.md`.
4. Commit with a message like `Add <subject> <topic> page` and `git push`.
