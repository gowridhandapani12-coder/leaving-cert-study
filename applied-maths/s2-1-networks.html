    Exam prep

    How Applied Maths is assessed, what the question words mean, and unlimited practice with worked solutions.

    Written exam · 80%

    Higher or Ordinary level, 2½ hours, set by the SEC. Covers the three contextual strands (networks, the physical world, a changing world), with modelling throughout.

    Modelling project · 20%

    A written report solving a real problem from a brief the SEC issues each year. Done in 6th year; the same brief for both levels, with a differentiated marking scheme. Sent to the SEC for marking.

    Top exam tips for this topic

    1. Draw it neatly. Label every vertex, put weights clearly on edges, and use arrows for directed edges.
    2. Say what the vertices and edges represent in the context, with units for weights.
    3. Use the exact words: path (no repeated vertex), cycle (back to the start), connected, directed.
    4. Check counts with the handshake rule: Σ degrees = 2 × edges.
    5. To show a graph is disconnected, name two vertices with no path between them.
    6. In a directed graph, give in-degree and out-degree separately.
    7. When you translate between a diagram, a list and a table, tick off each edge so none is missed or doubled.
    8. Past papers for this specification are on examinations.ie. The questions here are practice questions only.

    Odd/even

    HandshakeΣ deg(v) = 2E
    So

    degrees 3, 3, 2, 2 → 10 ÷ 2 = 5 edges
    RoutesPath: no repeated vertex
    Cycle
    a path that returns to its start
    Walk
    any route; may repeat
    LengthRoute weight = sum of edge weights
    12 + 7 + 6 + 9 = 34 km
    ConnectedA path between every pair of vertices
    Bridge

    Fewest edgesConnect n vertices: n − 1 edges
