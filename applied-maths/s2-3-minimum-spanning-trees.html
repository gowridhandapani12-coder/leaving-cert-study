Strand 2 · Networks and graphs

Connect every village.
Use the least cable.
Never close a loop.

A minimum spanning tree links every vertex of a network for the least total weight. Learn what trees and spanning trees are, then find the minimum one with Kruskal's and Prim's algorithms, on a diagram and on a distance table.

    Interactive

    Labs

    Build trees, beat the algorithm, then step through Kruskal's and Prim's algorithms on diagrams and on a distance table. Every result updates live. All networks and distances are illustrative.

    Tree or not?

    Tap a line to switch an edge on (solid) or off (dashed). The readouts say whether the graph is connected, has a cycle, and is a tree. Edges that lie on a cycle turn red.

    Edges
    1Make three different trees. How many edges does each one have?
    2Make a graph with 5 edges that is not a tree. What goes wrong?
    3Start with a tree. Switch one edge off, then a different one on. Is it still a tree?
    Beat the algorithm

    Seven villages and the cable routes between them (lengths in km). Tap routes to choose them. Make a spanning tree: every village reached, no cycles. Can you find the cheapest one?

    Your network
    Collect & fit

    Make random connected networks. For each one, record the number of vertices n, the number of edges, and the number of edges in a spanning tree (shown in red). Fit a line to tree edges against n.

    Kruskal step by step

    The edges are listed from smallest to largest. Press "Next edge": each one is accepted (green) unless it would make a cycle (red, crossed out). Coloured vertices show the pieces joining up.

    Network
    Steps
    1Before each press, say "accept" or "reject" out loud. Were you right?
    2Why does Kruskal's tree come in separate pieces part-way through?
    3Try random weights. Does Kruskal ever need to look at every edge?
    Prim step by step

    Pick a start vertex. The tree (red) grows one vertex at a time. Orange edges leave the tree; the dashed one is the cheapest, and it is added next.

    Start vertex
    Steps
    1Run Prim from A, then from G. Is the tree the same? The total?
    2Compare the order of the edges with Kruskal's order. Why is it different?
    3At every step the red edges form one piece. Is that true for Kruskal?
    Prim on a table

    The same algorithm on the distance table. Rows of vertices in the tree are crossed out; their columns are numbered. Your turn: tap the entry you think comes next (the smallest entry in a numbered column that isn't crossed out).

    Start vertex
    Steps
    1Do a whole table by tapping, with no mistakes.
    2Tap an entry in a crossed-out row. Why is it not allowed?
    3Check: the circled entries add up to the same total as Kruskal's tree.
    Cable planner

    A broadband company must link all the villages. Set the cost per km, force a route that must be used, block a route, or add a new village H. The minimum network and its cost update live.

    New village
    1Force route CF. How much extra cable does it cost?
    2Block a route that is in the minimum tree. What replaces it?
    3Add village H. One more village, but how much more cable? Explain.

    Exam prep

    Written exam · 80%

    Higher or Ordinary level, 2½ hours, set by the SEC. Covers the three contextual strands (networks, the physical world, a changing world), with modelling throughout.

    Modelling project · 20%

    A written report solving a real problem from a brief the SEC issues each year. Done in 6th year; the same brief for both levels, with a differentiated marking scheme. Sent to the SEC for marking.

    Top exam tips for this topic

    1. Kruskal: list every edge in order of weight first. Then show each edge you consider, marked accepted ✓ or rejected ✗ (cycle).
    2. Prim: state your start vertex and give the edges in the order they are added.
    3. Prim on a table: show the crossed-out rows, the numbered columns and the circled entries on the table itself.
    4. Check your tree: n vertices → n − 1 edges, no cycles, every vertex reached.
    5. Always give the total weight with units, then answer in context (e.g. the cost in €).
    6. Ties: either edge may be chosen; say which. A network can have more than one MST, all with the same total.
    7. "This link must be included": put it in first, then carry on with Kruskal's algorithm.
    8. Past papers for this specification are on examinations.ie. The questions here are practice questions only.
