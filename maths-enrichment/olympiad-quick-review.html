Olympiad quick review

A 15–20 minute read covering the ideas that come up again and again in Irish Maths Olympiad (IrMO) style papers. Each section lists what to know, the first thing to try, and one short worked example.

0How to play the paper

  • Read every question first (5 minutes). Star the one that looks friendliest and start there, not at Q1.
  • Try small cases. n = 1, 2, 3, 4, 5. Write them in a table. The pattern usually tells you the answer and the proof.
  • Guess the answer, then prove it. Most "find all" questions have a simple answer (e.g. only n = 1, or all primes, or x = y = z).
  • Partial marks are real. Write down the correct answer, the small cases, and any lemma you proved. A clear half-solution beats a messy nothing.
  • Write it up properly. Say what you are proving, number the steps, and finish with a clear conclusion. For "find all", check that your answers really work and show there are no others.
  • Stuck for 20 minutes? Move on. Come back with fresh eyes.

1Number theory

Know cold

  • Squares mod small numbers: mod 3 → 0, 1. mod 4 → 0, 1. mod 8 → 0, 1, 4. Cubes mod 9 → 0, 1, 8. Fourth powers mod 16 → 0, 1.
  • Factorise: a² − b² = (a−b)(a+b), aⁿ − bⁿ is divisible by a − b, and aⁿ + bⁿ is divisible by a + b when n is odd.
  • Fermat: p prime, p ∤ a → a^(p−1) ≡ 1 (mod p). Euclid: gcd(a, b) = gcd(a − b, b).
  • Number of divisors of p^a q^b … is (a+1)(b+1)…. It is odd only for perfect squares.
  • Last digits repeat in cycles (powers of 2: 2, 4, 8, 6). Digit sum ≡ number (mod 9).

First moves

  • Equation in integers? Take it mod something (try 3, 4, 8, 9, 7) to rule out cases, or factorise and list factor pairs.
  • Bound it: if one side grows faster, only small values can work. Check those by hand.
  • Look at parity (odd/even) first. It is the cheapest mod.
Example. Find all integers x, y with x² − y² = 2026.
x − y and x + y have the same parity (their sum is 2x). If both are odd, the product is odd. If both are even, the product is divisible by 4. But 2026 = 2 × 1013 is even and not divisible by 4. No solutions.
Example. Show n⁵ − n is divisible by 30 for every integer n.
n⁵ − n = n(n−1)(n+1)(n²+1). Divisibility by 2 and 3 comes from three consecutive numbers. For 5, use Fermat (n⁵ ≡ n mod 5), or check n ≡ 0, ±1, ±2: if n ≡ ±2 then n² + 1 ≡ 0. ✓

2Algebra

Inequalities

  • AM ≥ GM: (a+b)/2 ≥ √(ab), and in general (a₁+…+aₙ)/n ≥ ⁿ√(a₁…aₙ). Equality when all are equal.
  • Squares are ≥ 0: a² + b² + c² ≥ ab + bc + ca since it equals ½[(a−b)² + (b−c)² + (c−a)²].
  • Cauchy–Schwarz: (a₁² + a₂² + …)(b₁² + b₂² + …) ≥ (a₁b₁ + a₂b₂ + …)². Useful form: x²/a + y²/b ≥ (x+y)²/(a+b).
  • Always find the equality case first (often all variables equal). It tells you which inequality will work.

Polynomials

  • Vieta: for x² + px + q, sum of roots = −p and product = q. For a cubic x³ + ax² + bx + c: Σr = −a, Σrs = b, rst = −c.
  • Factor theorem: P(a) = 0 ⇔ (x − a) is a factor. Integer-coefficient P: a − b divides P(a) − P(b).
  • a³ + b³ + c³ − 3abc = (a+b+c)(a² + b² + c² − ab − bc − ca).

Functional equations

  • Substitute x = 0, y = 0, x = y, y = −x, y = 1. Find f(0) and f(1) first.
  • Check whether f is injective (f(a) = f(b) ⇒ a = b) or surjective. Then guess f(x) = x, f(x) = cx or a constant, and verify your answer in the original equation.
Example. a, b, c > 0 with a + b + c = 3. Show ab + bc + ca ≤ 3.
9 = (a+b+c)² = a² + b² + c² + 2(ab+bc+ca) ≥ 3(ab+bc+ca), using a² + b² + c² ≥ ab + bc + ca. So ab + bc + ca ≤ 3, with equality at a = b = c = 1. ✓
Example. Find all f: ℝ → ℝ with f(x + y) = f(x) + y.
Put x = 0: f(y) = f(0) + y. So f(x) = x + c. Check: x + y + c = (x + c) + y ✓. Answer: f(x) = x + c for any constant c.

3Geometry

Know cold

  • Angles in the same segment are equal. The angle at the centre is twice the angle at the circumference. An angle in a semicircle is 90°.
  • Cyclic quadrilateral ⇔ opposite angles add to 180° ⇔ a side subtends equal angles at the other two vertices. Most IrMO geometry is "prove these four points are concyclic" or uses it.
  • Tangent–chord angle equals the angle in the alternate segment. Tangents from a point are equal in length.
  • Power of a point: PA·PB = PC·PD for two chords (or secants) through P, and = PT² for a tangent PT.
  • Similar triangles (AA) give ratios. Angle bisector theorem: BD/DC = AB/AC.
  • Area = ½ab sin C = rs (r = inradius, s = semi-perimeter). Sine rule: a/sin A = 2R. Cosine rule.
  • Midpoint theorem; centroid divides each median 2 : 1.

First moves

  • Draw a big, accurate diagram with ruler and compass. A good diagram often shows you what's true.
  • Mark every angle in terms of the triangle's angles (A, B, C), then angle chase.
  • Look for hidden circles: two right angles on the same segment means the four points lie on a circle.
  • If nothing works, use coordinates (put the key point at the origin and a line on the x-axis). It's slow but sure.
Example. In acute triangle ABC, the altitudes BE and CF meet at H. Show that A, F, H, E are concyclic and that B, C, E, F are concyclic.
∠AFH = ∠AEH = 90°, so they add to 180°: AFHE is cyclic. ∠BFC = ∠BEC = 90° on the same side of BC, so B, C, E, F lie on the circle with diameter BC. ✓

4Combinatorics

Tools

  • Pigeonhole: n + 1 objects in n boxes puts two in one box. The skill is choosing the boxes (remainders mod n, pairs that sum to a fixed number, parity patterns).
  • Invariants: find something that never changes (a sum, a parity, a total mod 3, a colouring count). If the start and target values differ, the target can't be reached.
  • Monovariants: a quantity that always goes down (or up) shows the process must stop.
  • Colouring boards (chessboard, or stripes mod 3) to show a tiling is impossible.
  • Counting: C(n, k), stars and bars C(n + k − 1, k − 1), complementary counting, and double counting (count the same thing two ways).
  • Extremal principle: look at the largest/smallest element or the longest chain.
  • Induction: prove for n = 1, then show that n implies n + 1. Good for "for all n" and constructions.
Example. Show that among any 6 integers, two have a difference divisible by 5.
There are only 5 possible remainders mod 5 (the boxes). With 6 integers, two share a remainder, so their difference is divisible by 5. ✓
Example. The numbers 1, 2, …, 10 are on a board. A move replaces any two numbers a, b with a + b + 1. After 9 moves one number is left. What is it?
Each move increases the total by 1. Start total 55, plus 9 moves → 64, whatever order you choose. (Invariant: total − number of moves made.)
Watch out. In "show it's possible" questions, give an explicit construction and check it. In "show it's impossible" questions, look for an invariant or a colouring.

✓2-minute checklist before you go in

  • Squares mod 3, 4 and 8; cubes mod 9.
  • Factor pairs and parity for integer equations.
  • AM–GM, the sum-of-squares trick, and finding the equality case.
  • Vieta's formulas; P(a) − P(b) is divisible by a − b.
  • Functional equations: plug in 0, 1, x = y, then verify.
  • Cyclic quadrilaterals, the tangent–chord angle, and power of a point.
  • Pigeonhole (choose the boxes), invariants, colouring.
  • Small cases → guess → prove → check your answers work.
